How the max hammer is computed

true_cost  = hammer x (1+bp) x (1+tax) + retrieval + churn
retrieval  = 0 in pickup mode (the trip is a per-auction decision,
             shown in the header); ship mode shares one box per invoice
churn      = (list+pack minutes) x rate + materials
             + storage x months + value x capital_rate x months
net        = value x (1 - fee - promoted) - fee_fixed,   per listing
floor      : profit >= min_roi x true_cost
             min_roi = base_roi + roi_per_month x months_to_sell   (capital lots)
             min_roi = volume_roi                                  (volume lots: landed cost at max
             under volume_capital_max - the wage inside churn is the return, ROI is a buffer)
max_hammer = (net_after_churn / (1+min_roi) - retrieval) / ((1+bp)(1+tax))
             capped at the capital ceiling
floor_max  = melt x shop_payout / ((1+bp)(1+tax))
             break-even if the exit is a metals buyer, not eBay

Value derivation

Photo 2, base: the **Rookwood flame mark** (RP cipher ringed by flames) is impressed at centre, faint but unmistakable, with **'XLV'** and shape number **1084** below it. Rookwood dated its work with Roman numerals under the flame from 1901 onward, so **XLV = 45 = 1945**. That date is the whole valuation. Rookwood's 1940s output was mass-produced production ware in plain matte glazes during the company's decline - it is genuine Rookwood but the **common end**, not the hand-decorated art pottery that brings hundreds. A small 1940s ivory matte figural dish trades **$30-70**. Photo 1: the dish itself, ivory matte, no chips or hairlines visible; light soiling in the recesses. L = a plain production piece to a bargain buyer; M = listed properly as marked Rookwood with the date cipher photographed; H = an owl or a Rookwood-shape collector.

Why med confidence

med - the maker and the date are read directly off the base, which is most of what matters. I am deliberately pricing this DOWN rather than up: 'Rookwood' reads like a $200 name and this is not that piece, and I would rather say so than let the mark carry the number. At $3 it is still worth taking if Phil is bidding on anything else here.
