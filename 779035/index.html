How the max hammer is computed

true_cost  = hammer x (1+bp) x (1+tax) + retrieval + churn
retrieval  = 0 in pickup mode (the trip is a per-auction decision,
             shown in the header); ship mode shares one box per invoice
churn      = (list+pack minutes) x rate + materials
             + storage x months + value x capital_rate x months
net        = value x (1 - fee - promoted) - fee_fixed,   per listing
floor      : profit >= min_roi x true_cost
             min_roi = base_roi + roi_per_month x months_to_sell   (capital lots)
             min_roi = volume_roi                                  (volume lots: landed cost at max
             under volume_capital_max - the wage inside churn is the return, ROI is a buffer)
max_hammer = (net_after_churn / (1+min_roi) - retrieval) / ((1+bp)(1+tax))
             capped at the capital ceiling
floor_max  = melt x shop_payout / ((1+bp)(1+tax))
             break-even if the exit is a metals buyer, not eBay
